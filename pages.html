Local AI

AI summaries and questions

Let the assistant use a small AI model that runs on your own graphics card. Nothing about the pages you read is sent to any server.

Model

Bigger models write better summaries but need more memory and take longer. The model is downloaded once, the first time you use it.

Using it

Open the assistant with Alt + A, then use Summarise this page, or type a question about the page. Press the gear icon there to download or remove the model. If your computer does not support WebGPU, the assistant keeps using its built-in summaries.
