Extensions

Neira runs local extensions: small scripts that add features to pages you visit.

🧩

Find extensions and themes in the Chrome Web Store.

Neira's local extensions are a small, in-house format: a folder with a manifest.json and a JavaScript file. They run in a sandbox and can read the page you are on.

Each extension can register its own shortcuts. These are separate from the browser's shortcuts.

Parental Controls

SafeSearch, an educational allowlist, and daily screen-time budgets per category. Enforced inside the browser, not just hidden in the UI.

Parental controls are locked

Enter your PIN to view and change parental settings.

Parental controls are off. Set a PIN to turn them on.

Recover access

Enter the recovery code that was shown when you turned on parental controls. It looks like NEIRA-XXXX-XXXX-XXXX. Then choose a new PIN.

Lost the recovery code too? Close Neira, then create an empty file named exactly

DISABLE-PARENTAL-CONTROLS.txt

in the Neira profile folder, and start Neira again.

Save your new recovery code

This is the only time you will see it. Write it down somewhere safe — you will need it if you forget the PIN again.

Choose a PIN

4 to 8 digits. Only a parent should know this. You will need it to change or turn off parental controls.
